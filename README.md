# 实验室报价系统

一个双击即用的 Windows 桌面报价软件：随时维护检测项目与单价，快速制作报价单，一键导出可直接发给客户的精美 Excel 报价单。

## 功能

- **仪表盘**：报价单总数、本月报价金额、已确认金额、项目/客户数量，近 6 个月金额趋势图、状态分布、最近报价单快捷操作。
- **项目库**：随时维护检测项目与价格（编号、名称、分类、规格/检测依据、单位、常规价、趋势价、成本价、备注、启用状态）；支持分类管理、搜索筛选、分页；支持 Excel 模板批量导入（新增/更新）与导出备份。
- **收藏置顶**：常用项目点 ★ 收藏后自动置顶显示；项目库支持「只看收藏」筛选，报价时左侧项目库同样可只看收藏、直接点星收藏，快速找到常用项目。Excel 模板含「收藏」列，可批量标记。

## 两套价格（常规价 / 趋势价）

- 每个项目可维护**常规价**和**趋势价**两套价格；趋势价留空表示该项目没有趋势价。
- 趋势价若是**区间价或条件价**（如 `100-200元/样`、`<5组内100元/膜；200元/膜`），请把原文填到「趋势价说明」，报价时该项的「趋势价」选项会置灰，改用**手填价格**。
- 报价明细中每一行都有「价格类型」下拉：**常规价 / 趋势价 / 手填价格**。
  - 选常规价或趋势价 → 单价自动填入对应价格；
  - 直接修改单价 → 自动切为「手填价格」；
  - 无趋势价或趋势价为区间时，「趋势价」选项显示「趋势价（无）」并禁用，只能手填。
- Excel 导入/导出模板已包含「趋势价」与「趋势价说明」两列；导入时会自动识别带单位的价格文本（如 `60元/对`），区间价自动归入趋势价说明而不误填数值。
- **客户管理**：客户单位、联系人、电话、地址、税号、开户行、备注；建报价单时下拉选择自动带出联系方式。
- **报价单**：从项目库搜索勾选批量添加明细；明细按「分组（如 A 组 / 对照组）+ 每组样本数 × 检测指标数 × 重复实验次数」自动算出合计数量；可改单价、单项折扣、整单折扣与税率；每一项可单独填写备注，随报价单一起导出到 Excel；实时汇总小计/折扣/税额/总计并显示人民币大写；状态管理（草稿/已发送/已确认/已拒绝）；一键复制历史报价单；一键导出 Excel 并自动打开所在文件夹。
- **模块化报价**：一份报价单可拆成多个模块（部分），模块名称完全自定义（如"分子平台实验""WB 实验"），从项目库添加的项目会归入当前模块；明细与导出的 Excel 都按模块分段，每段显示项目及本模块小计，最后给出总额；模块可随时新增、重命名、删除。
- **临时项目**：客户临时提出的检测项目可在报价界面点「添加临时项目」，直接填名称、单位、单价、分组等加入本报价单；该项目**不会写入项目库**，明细中带「临时」标识，导出的 Excel 同样体现，适合一次性报价。
- **系统设置**：公司抬头信息（用于报价单排版）、单号规则（前缀+日期+流水）、默认折扣/税率/有效期、默认报价条款、导出目录、数据库备份与恢复。
- **Excel 报价单**：A4 专业排版——公司抬头、客户信息区、明细表格（斑马纹、全边框、千分位）、大写金额合计、折扣与税额说明、报价条款、双方签章栏，已设置打印区域与重复标题行，可直接打印或发送客户。

## 使用

- 双击 `dist/实验室报价系统.exe` 运行，无需安装 Python 或 Office。
- 导出的报价单默认保存在 `文档\实验室报价单`（可在设置中修改）。

## 内置初始项目（开箱即用）

程序已内置**科信研测 146 个检测项目**（16 个分类，含 18 项趋势价），首次运行自动带入，无需再手工导入：

| 分类 | 编号前缀 | 分类 | 编号前缀 |
|---|---|---|---|
| RT-qPCR | KX-RTQ | 取材 | KX-QC |
| WB | KX-WB | 切片制备 | KX-QP |
| ELISA | KX-ELISA | 染色 | KX-RS |
| 培养 | KX-PY | 拍照 | KX-PZ |
| 转染 | KX-ZZ | 分析 | KX-FX |
| 流式 | KX-LS | 动物代购 | KX-DW |
| 功能 | KX-GN | 饲养 / 操作 / 模型 | KX-SY / KX-CZ / KX-MX |

编号规则：`KX-<分类代码><三位序号>`，如 `KX-RTQ001`（普通引物合成）、`KX-RS026`。
项目清单与编号也同步在 `导入项目_科信研测报价单.xlsx`，可随时用它重新导入校对。
如需恢复出厂项目：系统设置 → 数据管理 → 「重置为内置数据」（当前数据会自动备份）。

## 数据存放与分发（随身模式）

程序默认采用**随身模式**：数据保存在程序自己目录下的 `data\labquote.db`，与程序放在一起，随时增删改都会实时写入。

```
实验室报价系统.exe
data\
  labquote.db     ← 项目库、客户、全部报价单
```

- **发给同事**：把整个程序文件夹压缩发送，或在「系统设置 → 数据位置与共享」点「生成可分发程序包(zip)」，一键把程序＋当前数据打包，同事解压后双击 exe 即可，数据自动识别、无需任何设置。
- **识别规则**：程序目录（或其 `data` 子目录）里存在 `labquote.db` 就自动使用；也可以剪切数据到别处恢复成本机模式。
- **其他可选位置**：设置页可切换为本机用户目录（`%LOCALAPPDATA%\LabQuoteSystem\data`），或指定共享盘/网盘同步目录供多人共用同一份数据。
- 数据以 SQLite 文件存放，可随时在设置页「立即备份」为 `.db` 文件，或「恢复数据库」导入他人的数据。

> 说明：exe 本身在运行时被系统锁定，无法把数据写进 exe 内部，因此采用「程序 + 同级 data 文件夹」的绿色方式，效果等同于数据跟着程序走。

## 技术栈

Python 3.12（标准库 http.server + sqlite3）· pywebview 桌面窗口（无 WebView2 时自动降级为浏览器打开）· openpyxl 生成 Excel · 原生 HTML/CSS/JS 前端 · PyInstaller 单文件打包。

## 目录结构

```
app/    后端：main.py 入口 / server.py 本地服务与 API / db.py 数据层 / export_excel.py Excel 生成
web/    前端页面：index.html + styles.css + core.js + views.js + quote.js
build.py    打包脚本（生成 dist/实验室报价系统.exe）
PLAN.md     实施方案
```
